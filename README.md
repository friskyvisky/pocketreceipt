# PocketReceipt

A personal expense tracker that scans receipts and categorizes spending automatically — built as a lightweight, installable web app (PWA) with a focus on privacy and simplicity.

## What it does

- Scans receipts using OCR to extract purchase details automatically
- Uses a self-learning classifier to categorize expenses over time — the more you use it, the smarter it gets at sorting your spending
- Works fully offline as an installable app (PWA) — install it to your home screen like a native app
- Built with INR formatting for everyday use in India
- Keeps data local and private — nothing is stored on a server you don't control

## Tech

- Vanilla HTML/CSS/JavaScript — no framework overhead
- Service worker for offline support and caching
- Gemini API for receipt OCR
- Local storage for on-device data persistence

## Why I built this

I wanted a simple way to track expenses without handing my financial data to a third-party app, and to explore how far AI-assisted development could take someone without a formal CS background. This was built solo using AI coding tools, with a focus on solving a real, everyday problem.

## Status

Actively maintained — built as a portfolio project while studying Business Administration and exploring AI-assisted product development.
